# MCQ & Quiz System

## Generation Sources

Users can generate MCQs from:

1. Upload PDF/DOCX
2. Topic / Prompt
3. Study Material from Knowledge Vault

## Settings

Question count:

- 5
- 10
- 15
- 20

Difficulty:

- Easy
- Medium
- Hard

AI model:

- Auto
- Fast
- Balanced
- Deep Think

## Quiz Modes

### Practice
No strict countdown.

### Timed
Time limit is applied per the configured quiz rules.

### Exam
More restrictive assessment-oriented mode.

## Scoring

Scoring is performed on the backend.

The frontend does not determine the authoritative score.

## Results

Results include:

- score
- percentage
- correct answers
- incorrect answers
- unanswered questions
- explanations
- timing information

## History

Quiz attempts are persisted and can be reviewed later.

## Export

MindQ provides branded PDF export generated server-side with OpenPDF.

## Save to Vault

Generated quizzes can be serialized into Knowledge Vault content for later reference.
