## Visual Style

MindQ should feel:

- premium
- modern
- intelligent
- educational
- professional
- calm

Avoid:

- childish UI
- excessive gradients
- neon effects
- excessive glassmorphism
- heavy shadows
- clutter

## Logo

Concept K is the selected visual direction:

brain + AI circuitry + Q.

## Icons

Lucide React is used for standard UI icons.

Custom MindQ assets are used selectively for branding and major feature areas.

## Themes

- Light
- Dark
- System

## Feedback

Use:

- toast notifications
- inline errors
- skeleton loading
- empty states
- meaningful success states

## Product Tour

The first-time user experience should introduce:

Dashboard
→ Knowledge Vault
→ AI Studio
→ MCQ generation
→ Quiz
→ Results
→ Pricing

The tour should point to real UI elements and work responsively.
